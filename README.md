# مفتاح حوشك

موقع عقارات يتثبت على الموبايل كتطبيق (PWA).

- `index.html`: الصفحة اللي يشوفها الناس (العروض، الخريطة، صفحة العقار، اتصال وواتساب).
- `admin.html`: لوحة الإدارة، ليك أنت بس (إضافة وتعديل العروض، الصور، مُباع أو مؤجَّر).
- `config.js`: الملف الوحيد اللي تعدّل فيه (رابط ومفتاح Supabase، الرقم، المدن).
- `supabase.sql`: إعداد قاعدة البيانات، يتشغل مرة وحدة بس.

الاستضافة: GitHub Pages (مجاني) + Supabase (مجاني).
